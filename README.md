# SIGHTLINE

**VALORANT tactical scouting console for coaches — opponent utility heatmaps, Operator/sniper profiling, and one-click anti-strat plans, built on pro match data.**

Status: 🚧 in development.

Built for [Cloud9 x JetBrains: Sky's The Limit Hackathon 2026](https://cloud9.devpost.com/) — Category 1 (VALORANT Tactical Scouting, Utility Placement & Operator Profiler).

## Data

Built on GRID esports data (hackathon starter set: VCT Americas, Masters, Game Changers 2025–2026). Raw GRID data is licensed hackathon-only and is **never committed to this repo** — only aggregates and charts derived from it (see `data/aggregates/`).
